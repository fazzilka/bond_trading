# Формат импорта

Production backend принимает только `.xlsx`. Файл Numbers или старый `.xls` нужно
предварительно экспортировать в XLSX.

## Защита загрузки

- максимальный размер по умолчанию — 10 MiB;
- проверяется расширение `.xlsx`;
- проверяется MIME XLSX/ZIP/octet-stream;
- метаданным не доверяют: содержимое обязательно открывается как реальная XLSX-книга;
- файл целиком не пишется в лог и не сохраняется на диск.

## Выбор листа и блока

Сначала ищется лист `Доход счёт 2026`. Если его нет, выбирается первый лист с ячейкой
`ISIN`. Строка с этой ячейкой считается заголовком, независимо от номера.

Чтение начинается со следующей строки и заканчивается перед первой полностью пустой
строкой. Оформление ячеек не влияет на пустоту. Поэтому в исходной книге строки 3–13
являются лотами, строка 14 завершает блок, а контрольные строки 15–16 не импортируются.

## Карта колонок

| Колонка | Значение | Поведение |
|---|---|---|
| B | ISIN | обязательно; trim, uppercase, format/check digit |
| C | наименование | используется для первичного short name |
| D | погашение/оферта | обязательно; нормализуется в `maturity`/`offer` |
| E | дата покупки | обязательно; `date` |
| F | период подачи на оферту | сохраняется как заметка |
| G | дата события | обязательно; `date` |
| H | количество | обязательно; Decimal > 0 |
| I | цена покупки за бумагу | обязательно; Decimal ≥ 0 |
| J | НКД покупки за бумагу | обязательно; Decimal ≥ 0 |
| K | сумма НКД | не импортируется, пересчитывается |
| L | комиссия покупки за бумагу | обязательно; Decimal ≥ 0 |
| M | стоимость покупки | не импортируется, пересчитывается |
| N | ручная цена целевого выхода | optional override; формула игнорируется |
| O–Q | купонные расчёты Excel | не импортируются как истина |
| R | комиссия выхода за бумагу | optional Decimal; default 0 |
| S–U | выход/прибыль Excel | не импортируются, пересчитываются |
| V | ручная плановая доходность | optional reference для сверки |
| W | текущая доходность Excel | не импортируется, пересчитывается |

Ручные обязательные поля не могут содержать формулу. Для optional расчётных/reference
полей формула означает «нет ручного значения», потому что итог всё равно строится
приложением.

Импортированная числовая цена из N хранится отдельно от данных MOEX с причиной
`Imported from source column N` и timestamp override.

## Валидация строк

ISIN обрезается, переводится в верхний регистр, проверяется по формату 12 символов и
по алгоритму контрольной цифры ISIN. Поэтому `RU000A107sg8` превращается в
`RU000A107SG8`.

Ошибка одной строки получает `row_number`, `field`, понятное `message` и исходное
значение, когда оно доступно. Остальные строки продолжают разбираться. Preview
показывает исходный и нормализованный ISIN до commit.

## Идемпотентность и дубликаты

Checksum считается по исходным байтам файла. Commit с тем же checksum и тем же листом
возвращает существующий `ImportBatch` и не создаёт лоты повторно. Внутри batch также
есть уникальность пары batch + номер строки.

Разные строки с одинаковым ISIN не дедуплицируются: это разные реальные покупки с
собственными датой, количеством, ценой и комиссией.

Preview хранится в памяти процесса 30 минут. После успешного commit он удаляется;
просроченный или неизвестный preview возвращает 404.

## API workflow

```text
POST /api/v1/imports/preview  multipart field: file
POST /api/v1/imports/commit   JSON: {"preview_id": "..."}
GET  /api/v1/imports/{batch_id}
```

UI выполняет тот же workflow на `/import` через HTMX preview и обычный подтверждающий
POST.
